# 🧬 DNA Sequence Analyzer

A Python-based bioinformatics tool designed for DNA sequence analysis.  
This project provides multiple functionalities to analyze DNA sequences, including validation, nucleotide composition analysis, reverse complement generation, transcription, translation, ORF detection, and FASTA file processing.

The project is developed as a learning and portfolio project combining **Bioinformatics, Python Programming, and Data Analysis**.

---

## 🚀 Features

### DNA Sequence Analysis
- ✅ DNA sequence validation
- ✅ Sequence length calculation
- ✅ Nucleotide frequency/count (A, T, G, C)
- ✅ GC content calculation
- ✅ AT content calculation

### Sequence Processing
- ✅ Reverse complement generation
- ✅ DNA to RNA transcription
- ✅ Protein translation
- ✅ Open Reading Frame (ORF) detection

### FASTA Handling
- ✅ FASTA file reading
- ✅ DNA sequence extraction from FASTA files

### Visualization & Interface
- ✅ Interactive Streamlit web interface
- ✅ Sequence statistics visualization
- ✅ User-friendly input options
